Quick Connection Guide
Android 9+ (Private DNS)
Go to Settings → Network & Internet → Private DNS → Private DNS provider hostname:
dns.srbh.io
Web Browsers (Chrome, Firefox, Brave)
Go to Settings → Privacy & Security → Use Secure DNS → Custom provider:
https://dns.srbh.io/dns-query
Linux (systemd-resolved)
Set DNS in /etc/systemd/resolved.conf:
DNS=dns.srbh.io DNSOverTLS=yes
Windows 11 (DoH)
Settings → Network & Internet → Wi-Fi / Ethernet → Edit DNS server assignment → Manual → Preferred DNS: 34.10.215.21 (Enable DoH).
